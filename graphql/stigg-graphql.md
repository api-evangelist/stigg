# Stigg GraphQL API

The Stigg GraphQL API provides full access to customer provisioning, subscription management, entitlement checking, usage reporting, and pricing plan management. Authentication uses the X-API-KEY header with a Full access key from the Stigg dashboard.

**Documentation:** https://docs.stigg.io/api-and-sdks/integration/backend/graphql

**GraphQL Properties:**

- GraphQL: https://api.stigg.io/graphql
